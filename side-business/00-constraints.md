本プロジェクトの全ての計画は、以下の制約を満たすこと。
計画を修正・拡張するときは、まずこのファイルとの矛盾がないかを確認する。

## 稼働リソース

| 項目 | 内容 |
|---|---|
| 稼働時間 | **週5〜10時間**（平日夜1〜2時間 + 週末に数時間） |
| 技術レベル | **少し書ける**（簡単なコードは読める・直せる。AI出力をレビューできる程度） |
| 資金 | 本人が拠出可能。ただし売上が立つまでは月額ランニング1,000円以内に抑える方針 |

| 開発手段 | Claude Code を主力とする |

## 発信スタンス

- **実名 OK / 顔出し NG**
- → 動画チャネル（YouTube 顔出し、TikTok）は原則使わない
- → 技術記事（Zenn / Qiita / note）、X（実名またはハンドルネーム）、SEO を主軸にする
- → 特定商取引法に基づく表記で自宅住所を晒す件は別途対策が必要（`research/02-monetization-legal.md` 参照）

## 収益モデルの好み

- **こだわりなし** — 調査結果にもとづき、勝率の高いものを推薦する

## 収益目標（マイルストーン）

| 段階 | 目標 | 位置づけ |
|---|---|---|
| M1 | **月商 1,000円** | 「他人が金を払う」ことの検証。金額ではなく事実が目的 |
| M2 | 月商 1万円 | 再現性の検証。M1がまぐれでないことの確認 |
| M3 | 月商 10万円 | スケールの検証。ここから先は時間ではなく仕組みで伸ばす |

## 判断基準（迷ったらこれで決める）

1. **週10時間で回るか** — 回らない案は、どれだけ儲かりそうでも却下
2. **売上0円のとき赤字がいくらか** — 月1,000円を超える固定費は原則NG
3. **やめるときのコストが低いか** — 在庫・長期契約・返金義務が重い案は避ける
4. **顔出し不要か** — 顔出し前提の集客に依存する案は却下
