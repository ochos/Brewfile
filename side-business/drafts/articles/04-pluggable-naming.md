この記事は、次のような方に向けて書いています。

- **「400G-DR4 と FR4 の違い」を調べていて、いまこの瞬間、選定や確認で困っている方**
- **営業・技術営業・調達など、発注書に書く型番を間違えたくない方**

扱うのは「**光トランシーバの型番をどう読むか**」と「**発注の前に何を確認するか**」の2点だけです。前提知識は要りません。

:::message alert
**先にお断りです。** 本記事の諸元（到達距離・芯数・波長など）は**公開情報をもとに整理したもの**で、原典の規格書やデータシートを1件ずつ検証したものではありません。**実際の選定・発注にあたっては、必ずメーカーのデータシートと機器側の対応表で確認してください。** この記事の価値は数値そのものではなく、**「何を確認すべきか」がわかること**にあります。
:::

## まず、たとえ話で

定食屋で「大盛りで」と頼んだとします。店によって、出てくるものが違います。ご飯だけが増える店、おかずまで増える店、器ごと大きくなる店。

厄介なのは、**注文の時点では誰も気づかない**ことです。頼んだ側は「ご飯が増える」と思い、出す側は「器を大きくする」と思っている。それでも会話は成立してしまいます。言葉が同じだからです。気づくのは、出てきたときです。そして、どちらも間違ってはいません。**それぞれの店では、それが正しい「大盛り」**なのです。

光の部品にも、同じことが起きます。「400G」という同じ名前の中に、**中身の違うものが複数あります**。片方は太いケーブルを使い、片方は細いケーブルを使う。速さは同じなのに、**必要になるものが違う**。しかも両方の担当者が、それぞれの現場では正しいことを言っている。だから会話は噛み合わないまま最後まで進みます。

この記事は、その取り違えを止めるためのものです。**技術を深く理解するための記事ではなく、確認の順番を決めるための記事**だと思ってください。

## 型番は3つの部分でできている

`400GBASE-DR4` のような名前は、意味のある3つの部分に分けられます。

```
400GBASE-DR4
└┬─┘└┬─┘└┬┘│
 │   │   │ └── レーン数（4）
 │   │   └──── 到達距離の区分（DR）
 │   └──────── ベースバンド伝送を表す固定の文字列
 └──────────── 速度（400 Gbit/s）
```

つまり **`[速度]BASE-[到達距離コード][レーン数]`** という構造です。

問題は、3つ全部読んでも**知りたいことの多くが分からない**ことです。必要なファイバが**8芯なのか2芯なのか**。コネクタが **MPO なのか LC なのか**。**100G × 4 に分けられるのか、400G のまま1本なのか**。**名前がはっきり答えているのは、速度だけです。**

### 到達距離コード

おおよその対応は次のとおりです。由来（何の略か）は解説によって説明が食い違うので、**由来は覚えず、対応だけ押さえる**のが安全です。

| コード | ファイバ | おおよその到達距離 |
| --- | --- | --- |
| **SR** | マルチモード | 100m 級（世代や OM 種別で変わる） |
| **DR** | シングルモード（1310nm 帯） | 500m 級 |
| **FR** | シングルモード（1310nm 帯） | 2km 級 |
| **LR** | シングルモード | 10km 級（**ただし後述の例外に注意**） |

:::message
**「LR = 10km」と暗記するのは危険です。** 400G の世代では、同じ `LR4` でも 6km を想定した規格名と 10km の仕様が併存している、という指摘があります（筆者は原典未確認なので断定しません）。**覚えるべきは値ではなく「距離は名前だけでは確定しない」という一点です。**
:::

## 400G-DR4 と 400G-FR4 — 何がどう違うのか

検索でこの記事にたどり着いた方は、まずこの表を見てください。

| | **400GBASE-DR4** | **400GBASE-FR4** |
| --- | --- | --- |
| **末尾の「4」が指すもの** | **ファイバの本数（並列レーン）** | **波長の数** |
| 多重の仕方 | **並列**。4本すべて同じ波長 | **波長多重**。1対のファイバに4波を載せる |
| 波長 | 1310nm 帯の**単一波長** | **1271 / 1291 / 1311 / 1331 nm**（20nm 間隔の CWDM グリッド） |
| **必要な芯数** | **8芯**（送信4 + 受信4） | **2芯**（送信1 + 受信1） |
| **コネクタ** | **MPO-12**（12芯のうち8芯だけ使う。研磨は APC が一般的） | **デュプレックス LC** |
| おおよその到達距離 | **500m 級** | **2km 級** |
| **100G × 4 への分割** | **できる**（4 × 100GBASE-DR） | **できない**。400G のまま1本 |
| 規格 | IEEE 802.3bs（2017） | IEEE 802.3cu（2021）。先に 100G Lambda MSA が策定し IEEE が取り込んだ |

**速度は同じ 400G です。それ以外がほとんど違います。**

### 末尾の「4」が数えているものが違う

この記事でいちばん伝えたいのは、この一点です。DR4 は、1310nm の**同じ色の光**を、**4本のファイバに並べて**流します。波長多重ではありません。トンネルを4本掘っているようなものです。一方 FR4 は、**色の違う4つの光**を、**1対のファイバに重ねて**流します。こちらが波長多重で、1本のトンネルに車線を4本引いている。

同じ「4」でも**数えている対象が違う**ので、帰結が正反対になります。DR4 は物理的に分かれているから**先で4本の 100G にほどけ**、本数が要るから **8芯**。FR4 は光として重なっているから**ほどけず**、1対で済むから **2芯**。

:::message alert
**「400G で」という合意だけでは、次のどれも決まっていません。**
サービスとして 400G が1本なのか、100G が4本なのか。ファイバが 8芯必要なのか 2芯で足りるのか。コネクタが MPO なのか LC なのか。**「400G 同士だから大丈夫」は、判定になりません。**
:::

### 芯数を知りたいときは、距離コードを見る

型番を見たときの目安はこうです。**`D` の距離コード（DR / DR4）は並列で、MPO、芯数 = レーン数 × 2。`F` や `L`（FR4 / LR4 など）は波長多重で、デュプレックス LC、芯数は 2。** 末尾の数字ではなく距離コードのほうを見る、というのが入口になります（目安なので、**最終確認はデータシートで**）。

現場では、この違いが「どちらを選べるか」を先に決めてしまいます。**既設が2芯しかない区間に DR4 は使えず**（8芯必要）、**1つの 400G ポートを4台に配りたいのに FR4 を買っても分けられません。** 接続の形は、実務上ほぼ次の3つに落ちます。

- **MPO ⇔ MPO**（DR4 ⇔ DR4）— 400G を 400G のまま 8芯で渡す
- **MPO ⇔ ブレイクアウト（MPO → LC × 4）** — 1つの 400G ポートを4本の 100G に分けて配る
- **LC ⇔ LC の2芯**（FR4 ⇔ FR4）— 400G を1対のファイバで丸ごと渡す。既設が2芯ならこれ

## 「挿さるのにリンクしない」がいちばん厄介

物理的に挿さらない組み合わせは、実は軽いほうです。その場で気づけるからです（MPO-16 と MPO-12 はキーの位置が違って勘合しませんし、QSFP-DD と OSFP はケージが違って入りません）。**時間を取られるのは「挿さるのにリンクしない」ほうです。**

代表例が **400G DR4 と 100G PSM4** です。どちらも MPO-12 なので**物理的には勘合します**。しかしレーンの速度が違う（100G PAM4 × 1 と 25G NRZ × 4）ため、リンクしません。「ケーブルは合っているのに繋がらない」状態になり、切り分けが長引きます。DR4 のブレイクアウトを計画するときは、ここが最大の落とし穴です。

**DR4 → 4 × 100G のブレイクアウトが成立する条件**

1. **相手側が「1波長で 100G」のモジュールであること**（100GBASE-DR / FR1 / LR1 系）。**従来の 4 × 25G 系（100GBASE-SR4 / LR4 / CWDM4 / PSM4）とはリンクしません**
2. **両端で FEC の設定が揃っていること。** 揃わないと「光は来ているのにリンクしない」状態になります
3. **各支線の距離が想定範囲に収まっていること**（DR4 なら支線側も 500m 級）
4. **スイッチ側が、そのポートを 4 × 100G として扱えること。** モジュールの能力とは別問題です。**筆者は原典で確認できていないので、必ず機器のドキュメントで確認してください**

ケーブルは、MPO 1個から LC デュプレックスが4本出る構成（8芯）になります。

## 標準化が終わる前は、名前がばらつく

検索でつまずきやすいのがこれです。**新しいものが出たとき、標準化が終わる前に各社が独自の名前を付けます。**

きれいな実例が「**DR4 と同じ構成のまま、もう少し遠くまで届くようにしたもの**」です。並列シングルモード（8芯・MPO-12・1310nm 帯の単一波長）は DR4 と同じで、レーンあたりの光の余裕を増やして 2km 級にしたもの。各レーンが 100G-FR 相当になるので、**2km の 100G 支線を4本引ける**のが売りです。これに、次のような名前が並びました。

| 呼び方 | 出どころ |
| --- | --- |
| `400G-DR4+` / `400GBASE-DR4+` | ベンダー・販売業者の通称 |
| `400G-XDR4` | Arista の型番 `QDD-400G-XDR4` に由来 |
| `QDD-4X100G-FR-S` | Cisco の型番。名前に DR も XDR も入っていない |
| `4 × 100G-FR` | 機能をそのまま並べた呼び方 |
| **`400GBASE-DR4-2`** | **IEEE 802.3df（2024）で後から標準化された正式名**（`-2` は 2km の意） |

**おおむね同じものを指しています。** ただし **400G 1本として使えるのか、100G ブレイクアウト専用なのかという位置づけまで同じとは限りません**（Cisco の `QDD-4X100G-FR-S` が 400G 単体リンクに対応するかは、筆者は確認できていません）。**同じ機能だと言い切る前に、両社のデータシートを突き合わせてください。**

流れはこうです。**標準には 500m（DR4）と 2km（FR4、2芯）しかなかった → 市場が「2km の並列・ブレイクアウト用」を欲しがり、各社が別々の名前を付けた → 後から IEEE が標準名を与えた。** そして**標準名が付いたあとも、古い呼び方は消えません。** カタログには新しい名前、会話では古い名前。どちらも間違いではないので、訂正されないまま併存します。

なお、現場では `DR+` という短い言い方も聞きますが、**それが `DR4+` と同じものを指しているかは、名前だけでは確定しません。** 口語の省略である可能性が高いものの、断定はできません。**聞いたら、レーン数まで含めた表記を確認してください。**

### 名前の出どころは1つではない

名前を決めている主体は複数あります。**IEEE 802.3** は光の仕様（波長・パワー・距離）と `xxxBASE-yyy` という名前を、**100G Lambda MSA** は1波長 100G の光仕様を（IEEE より先行することが多い）、**QSFP-DD / OSFP MSA** は**筐体の形やケージだけ**を決めます。

> **「モジュールが挿さるか」を決めるのは、形状の規格（QSFP-DD / OSFP）。**
> **「光がつながるか」を決めるのは、光の仕様（DR4 なのか FR4 なのか）。**
> **決めている団体すら違います。**「QSFP-DD 同士だから大丈夫」は何の保証にもなりません。

表記の傾向として、`400GBASE-XXX`（`BASE` あり）は IEEE 名、`400G-XXX` は MSA の仕様名、`QDD-...` は各社の型番、という区別はあります。ただし**商品名では守られていません**（IEEE 名でないのに `400GBASE-DR4+` と書く販売サイトが実在します）。**「BASE が付いているから標準名」とは判断できず**、逆向きの「**BASE が付いていなければ、まず IEEE 名ではない**」という片側だけが比較的安全です。

## 発注・接続の前に確認すること

そのまま持ち帰れる形にしたものです。**発注の前、できれば最初の打ち合わせの時点で**揃えてください。

- [ ] **両端の光の仕様名が、完全に一致しているか** ← **最優先。これ以外はすべて補助です**
- [ ] サービスとして **400G が1本か、100G が4本か**
- [ ] ファイバは **MPO か、LC 2芯か**。**芯数はいくつか**
- [ ] ケーブルの構成（MPO ⇔ MPO / MPO ⇔ LC × 4 のブレイクアウト / LC 2芯 ⇔ LC 2芯）
- [ ] コネクタの**研磨（APC / UPC）と極性**が、両端とケーブルで揃っているか
- [ ] **到達距離は足りているか。逆に、過剰ではないか**（短距離に長距離用を使うと、費用が無駄になるだけでなく、受け側に光が強すぎる懸念もあります）
- [ ] ブレイクアウトするなら、**相手側が1波長 100G のモジュールか**（4 × 25G 系ではないか）、**スイッチ側がそのポートを分割できるか**
- [ ] **両端の FEC 設定が揃うか**
- [ ] その呼び方は**正式な規格名か、ベンダーの通称か**。通称なら、**正式名も併記して発注する**
- [ ] **機器がそのモジュールを受け付けるか**（型番が同じでも、機器側の対応リストで弾かれることがあります）

:::message
**早く気づくほど、傷は浅く済みます。**
打ち合わせ中に気づけば、検討をやり直すだけ。モノが届いてから気づけば、手配のやり直し。**開通して接続したあとに気づくのが、いちばん高くつきます。** だから確認は、早いほど価値があります。
:::

## まとめ

- 型番が答えているのは、**ほぼ速度だけ**
- **末尾の数字が何を数えているかは、型番によって違う。** DR4 は**ファイバの本数**、FR4 は**波長の数**
- 芯数を知りたいなら**距離コードを見る**。`D` は並列で MPO・8芯、`F` / `L` は波長多重で LC・2芯。**DR4 は 4 × 100G に分けられ、FR4 は分けられない**
- 怖いのは「挿さらない」ではなく **「挿さるのにリンクしない」**（DR4 と 100G PSM4 は同じ MPO-12）
- 標準化の前は各社が名前を付けるので、**同じものに複数の名前がある**
- 合わせるべきは**両端の光の仕様名の一致**

繰り返しますが、**本記事の数値は公開情報を整理したものです。発注前に必ずデータシートと機器側の対応表で確認してください。** 持ち帰っていただきたいのは数値ではなく、**確認すべき項目のリスト**のほうです。
