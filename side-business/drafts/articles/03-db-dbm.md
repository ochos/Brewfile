この記事は、次のような方に向けて書いています。

- **光伝送の担当に配属されたばかりで、資料に出てくる dB と dBm の使い分けが曖昧な方**
- **営業・技術営業・企画・調達など、技術者ではないけれど、「受光レベルが −20 で…」といった会話についていきたい方**

扱うのは **dB と dBm** の一点だけです。定義、演算のルール、暗算の道具、そして実際に使う場面まで、この記事だけで完結させます。前提知識は要りません。

光伝送を学び始めた人が最初につまずくのは、たいていここです。そして**ここを外したまま先へ進むと、後の話がすべて曖昧になります**。逆に言えば、ここだけは1回で片づけられます。

## まず、たとえ話で

身長の話で考えます。

「170cm です」と「去年より 10% 伸びました」。この2つは、まったく種類の違う言い方です。前者は**絶対的な大きさ**、後者は**比**です。

比のほうは、それだけでは何も決まりません。「10% 伸びた」と言われても、元が何cm だったかを知らなければ、いま何cm なのかはわかりません。**比は、絶対的な大きさと組み合わせて初めて意味を持ちます。**

そして、この2つは混ぜてはいけません。「170cm から 10% 伸びた」は意味が通ります。しかし「**170cm と 165cm を足す**」は、何も意味しません。2人並べても 335cm の人にはならないからです。

光の世界では、**絶対的な大きさが dBm、比が dB** です。**dBm どうしを足してはいけない**のは、身長を足してはいけないのと同じ理由です。

では、なぜこんな単位をわざわざ使うのか。**光は進むほど、掛け算で弱っていく**からです。半分になり、その半分になり、さらに半分になる。掛け算のまま追いかけるのは面倒です。そこで、**対数にして足し算に変える**。それが dB の正体です。

:::message
ここまでで、この記事の結論はほとんど言い終わっています。以降は、それを実際に使えるようにする話です。
:::

## なぜ対数を使うのか

光ファイバを進む光は、距離に応じて**一定の割合で**弱くなります。一定の**量**ずつ減るのではありません。**一定の割合**です。

たとえば、ある区間を通るたびに光が半分になるとします。3区間通れば、

$$
\frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}
$$

途中で増幅器を入れて持ち上げるのも同じで、**掛け算**です。コネクタや部品を通るたびの目減りも掛け算。つまり光の設計とは、**掛け算と割り算の長い連鎖**を追いかける作業になります。これは暗算できません。

ここで対数を使います。覚えるべき性質は1つだけです。

$$
\log(A \times B) = \log A + \log B
$$

**掛け算が足し算になる。** これだけです。この変換をしておけば、区間の損失も、増幅器の利得も、部品の損失も、**すべて足し引きだけで見通せる**ようになります。

もう一つ利点があります。光の強さは、扱う範囲が非常に広い。送信端の光と、長距離を渡ったあとの光では、桁がいくつも違います。対数にすれば、その広い範囲が**扱いやすい2桁程度の数字の並び**に収まります。

## dB は比、dBm は絶対値

定義はこれだけです。

**dB（デシベル）** — 2つのパワーの**比**を対数にしたもの。単位を持ちません。

$$
\mathrm{dB} = 10 \log_{10}\left(\frac{P_2}{P_1}\right)
$$

**dBm** — **1mW を基準**にしたパワーの絶対値。

$$
\mathrm{dBm} = 10 \log_{10}\left(\frac{P}{1\,\mathrm{mW}}\right)
$$

**dBm の "m" は「1mW を基準にしている」という印**です。基準がくっついているから絶対値になる。dB には基準がないので、比のままです。

定義から、いくつかがすぐ出ます。

| 値 | 意味 |
| --- | --- |
| 0 dBm | ちょうど 1mW |
| 0 dB | 変化なし（1倍） |
| 正の dB | 増えた（利得） |
| 負の dB | 減った（損失） |

なお、$\log$ の前に **10** が付いているのは、比べているのが**パワー**だからです。電圧や振幅のように、2乗するとパワーになる量を比べるときは 20 を掛けます。光の話では基本的にパワーを扱うので、**10 のほうだけ覚えておけば足ります**。

## 演算のルールは3つだけ

ここが実務の中心です。

| 式 | 結果 | 意味 |
| --- | --- | --- |
| dBm − dBm | **dB** | 2点の差は「比」。区間の損失が出る |
| dBm + dB | **dBm** | 絶対値に、利得や損失を足す |
| **dBm + dBm** | **意味を持たない** | 身長どうしを足すのと同じ |

**dBm + dBm がなぜ無意味なのか。** 対数の世界で足すことは、元の世界で掛けることです。パワーとパワーを掛けた量には、光伝送で意味がありません。つまり「足してはいけない」というより、**足しても指す対象が存在しない**のです。

この3つは、**単位の帳尻合わせとしても使えます**。長い計算の最後に出てきた値が dBm なのか dB なのかを追っておくと、途中で式を間違えたときに気づけます。「損失を出したはずなのに単位が dBm になっている」なら、どこかで引き算すべきところを足しています。

:::message alert
**「2つの光を合わせたら合計はいくつか」を知りたい場合はあります。**
そのときは **dBm のまま足さず、いったん mW に戻して足し、また dBm に直します**。
たとえば同じ強さの光を2つ合わせれば合計は2倍。2倍は次節のとおり約 +3dB なので、答えは「**+3dBm**」ではなく「**元の値 +3dB**」です。
:::

## 暗算の道具 — 「3」と「10」で作る

覚えるのは2つだけです。

| 値 | 倍率 |
| --- | --- |
| **3 dB** | **約 2倍** |
| **10 dB** | **10倍** |

$10\log_{10}2 = 3.01$ なので、3dB は 2倍のごく良い近似です。この2つを足し引きで組み合わせれば、たいていの値はその場で出せます。

- 6 dB = 3 + 3 → 2 × 2 = **4倍**
- 9 dB = 3 + 3 + 3 → **8倍**
- 13 dB = 10 + 3 → **20倍**
- 20 dB = 10 + 10 → **100倍**
- 7 dB = 10 − 3 → 10 ÷ 2 = **5倍**
- 4 dB = 10 − 3 − 3 → 10 ÷ 4 = **2.5倍**

マイナス側は、そのまま逆数にするだけです。

- −3 dB → **半分**
- −6 dB → **1/4**
- −10 dB → **1/10**
- −20 dB → **1/100**

**近似の精度も知っておくと安心です。** 7dB の正確な値は 5.01倍、13dB は 19.95倍。**「3 と 10 で作った答え」は、実用上ほぼ正確**です。

### 小さい dB を「割合」に直す

損失の話では、1dB 未満の細かい値も出てきます。これも定義から出せます。

| 損失 | 残る割合 |
| --- | --- |
| −0.5 dB | 約 89% |
| −1 dB | 約 79% |
| −3 dB | 約 50% |

**−1dB で2割が消える**、という感覚を持っておくと、「たかが 1dB」と思わずに済みます。そして重要なのは、**この目減りが区間ごとに掛け算で積み上がる**ことです。だからこそ、足し算で追えるようにしておく価値があります。

## マイナスの dBm で混乱しないために

初学者がよく引っかかるのがここです。

**−30dBm と −20dBm では、どちらが強いか。**

答えは **−20dBm** です。−20 のほうが 10dB 大きい、つまり **10倍強い**。数直線の上では −30 のほうが左（小さい）ですが、日常の感覚では「マイナス30のほうが大きく減っている」ように見えてしまい、逆に読み違えることがあります。

整理しておきます。1mW を基準にした絶対値なので、こうなります。

| dBm | 実際のパワー |
| --- | --- |
| +20 dBm | 100 mW |
| +10 dBm | 10 mW |
| 0 dBm | 1 mW |
| −10 dBm | 0.1 mW |
| −20 dBm | 0.01 mW |
| −30 dBm | 0.001 mW |

**「dBm の値が大きいほど、光は強い」。** マイナスが付いていても同じです。

## 実際に使う場面

### その1 — 区間の損失を出す

区間の入口と出口で光の強さを測り、**dBm どうしを引きます**。差が **dB**、すなわちその区間で失われた割合です。

$$
(\text{入口の dBm}) - (\text{出口の dBm}) = (\text{区間の損失 dB})
$$

これが、光伝送でもっとも頻繁に行われる計算です。「入口 dBm − 出口 dBm」で単位が dB になる、という帳尻がここでも効いています。

### その2 — パワーバジェット

送信端の光の強さから始めて、**通っていくものを順に足し引きしていく**表を作ります。これをパワーバジェットと呼びます。

| 項目 | 種類 | 演算 |
| --- | --- | --- |
| 送信端の光の強さ | dBm | 出発点 |
| 合波器の損失 | dB | 引く |
| 区間の損失 | dB | 引く |
| 増幅器の利得 | dB | 足す |
| 分波器の損失 | dB | 引く |
| **受信端の光の強さ** | **dBm** | **結果** |

**dBm で始まり、途中はすべて dB の足し引き、結果はまた dBm。** これが対数を使う最大の理由です。倍率のままなら、この表は掛け算と割り算の列になり、見通しが一気に悪くなります。

数字を1本通してみます。**以下の値は、計算の形を見せるためだけの仮の数字です。実際の値は使う機器と区間で決まります。**

```
送信端            +2 dBm
合波器の損失       −4 dB   →  −2 dBm
区間の損失        −18 dB   → −20 dBm
増幅器の利得      +15 dB   →  −5 dBm
分波器の損失       −4 dB   →  −9 dBm
------------------------------------
受信端                       −9 dBm
```

やっていることは、**足し算と引き算だけ**です。もし倍率のまま書いていたら、「1.58mW に 0.398 を掛け、0.0158 を掛け、31.6 を掛け…」という列になり、途中でいまどこにいるのかがわからなくなります。

## 受け取れる範囲には、下限も上限もある

上の表の最後に出てきた**受信端の光の強さ**。この値には、**満たすべき範囲**があります。

弱すぎると読めない——これは直感どおりです。光が届かなければ信号になりません。

**問題は反対側です。強すぎてもいけません。**

受け取る側の素子には、**扱える光の強さに上限があります**。それを超えると信号が正しく読めなくなり、さらに超えると**素子そのものを傷めます**。壊れれば交換するしかありません。

:::message alert
**「強いほうが安全」は成り立ちません。**
遠くまで届くように作られた部品は、**そのぶん強い光を出します**。それを短い距離で使うと、受け取る側には**過剰な光**が入ります。**距離が短いことは、この場合まったく安全ではありません。**
:::

だからパワーバジェットは、**下限を満たすためだけの表ではありません**。上限を超えていないかを見る表でもあります。**両側から挟んで、その範囲に入れる**。それが設計です。

具体的な上限・下限の値は、使う部品の仕様書に書かれています。**この記事で覚えるべきは値ではなく、「両側にある」という構造のほう**です。

## まとめ

- 光は**掛け算で弱る**。対数にすると**掛け算が足し算になる**。それが dB を使う理由
- **dB は比**（単位なし）。**dBm は 1mW を基準にした絶対値**。"m" が基準の印
- **dBm − dBm = dB** ／ **dBm + dB = dBm** ／ **dBm + dBm は意味を持たない**
- 合計パワーを出したいときは、**mW に戻して足してから dBm に直す**
- **3dB ≈ 2倍、10dB = 10倍**。この2つの足し引きで、たいていの値は暗算できる
- **dBm はマイナスでも「値が大きいほど強い」**
- 受信端には**下限と上限の両方**がある。**強ければ安全ということはない**

数字を覚えるのではなく、**どの定義から出てきた数字かを追えるようにしておく**こと。前提が変わったときに気づけるのは、それだけです。
