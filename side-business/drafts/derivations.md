## 1. OSNR の基準帯域定数「+58」の正体

### なぜ重要か

実務ブログで「1スパンの OSNR」を **`P_TX + G − L − NF`** と書いている例がある。**これは誤り。**
利得 G が損失 L と相殺してしまい、健全なリンクを不良と誤判定する。

記事⑦「つまずきポイント」の最有力ネタ。**そして導出できるので出典が不要。**

### 導出

OSNR は「信号パワー」と「基準帯域内の雑音パワー」の比。基準帯域内の自然放出光の下限は次で決まる。

```
h・ν・B_ref
```

| 記号 | 意味 | 値 |
|---|---|---|
| h | プランク定数 | 6.62607015 × 10⁻³⁴ J·s（SI定義値） |
| ν | 光周波数 | c / λ = 193.41 THz（λ=1550nm） |
| B_ref | 基準帯域 | Δν = c·Δλ / λ² = **12.48 GHz**（Δλ=0.1nm） |

```
h・ν・B_ref = 1.5992 × 10⁻⁹ W = 1.5992 × 10⁻⁶ mW

10・log₁₀(1.5992 × 10⁻⁶) = −57.96 dBm  ≈  −58 dBm
```

したがって:

```
OSNR = P_in − NF + 58        （P_in はアンプ入力パワー [dBm]）
     = P_TX − L − NF + 58    （単スパン）
```

**+58 の正体は「0.1nm 幅の量子雑音の下限が −58 dBm である」ということ。** マジックナンバーではない。

### 誤った式との比較

P_TX = 0 dBm、スパン損失 L = 22 dB、利得 G = 22 dB（損失を補償）、NF = 5 dB のとき:

| | 式 | 結果 |
|---|---|---|
| 誤 | P_TX + G − L − NF | **−5.0**（健全なのに不良と判定してしまう） |
| 正 | P_TX − L − NF + 58 | **31.0 dB** |
| | 差 | **36 dB** |

### 誤りの本質（記事に書く一文）

> **利得 G は式に現れない。** OSNR を決めるのはアンプ**入力**パワー（P_TX − L）と NF であり、
> G は損失を補償するだけで **SN 比を改善しない**。増幅は信号と雑音を同時に持ち上げる。

### 検証コード

```python
import math
h, c, lam, dlam = 6.62607015e-34, 2.99792458e8, 1550e-9, 0.1e-9
nu = c / lam
B  = c * dlam / lam**2          # 0.1nm → 12.48 GHz
print(10*math.log10(h*nu*B*1e3))   # → -57.96 dBm
```

**この計算は自分で再現できる。** 記事に載せれば、読者も検証できる。
「出典: ○○のブログ」より強い。

## 2. 波長と周波数の換算（Δν = c·Δλ / λ²）

同様に第一原理。0.1nm が 12.48 GHz になる理由。ITU グリッドの説明（本の第1章）でも使う。

```
ν = c/λ  →  |dν/dλ| = c/λ²  →  Δν ≈ c·Δλ/λ²
```

λ=1550nm、Δλ=0.1nm で Δν = 12.48 GHz。
**50GHz グリッドが約 0.4nm 間隔**であることも、ここから出る。

## 3. dB と dBm の関係

- dB は**比**（無次元）。dBm は **1mW を基準にした絶対値**
- dBm − dBm = dB（差は比になる）
- dBm + dB = dBm（絶対値に利得/損失を足す）
- **dBm + dBm は意味を持たない** ← つまずきの定番

これも定義から説明でき、出典不要。

## 4. DSF が DWDM に向かない理由 — 四光波混合の効率は分散から計算できる

**本の第4章の核。** 日本の現場（DSF 区間が多い）に直結し、かつ**出典なしで数値を示せる。**

### なぜ分散ゼロが問題なのか

四光波混合（FWM）は、複数の波長が同時に存在するとき、混合積が別の波長に落ちる現象。
発生するかどうかは**位相整合**で決まる。

- **分散があると**、波長ごとに伝搬速度が違う → 位相がずれていく → **混合積が積み上がらない**
- **分散がゼロだと**、位相が揃ったまま進む → **混合積が効率よく積み上がる**

DSF（G.653）は **1550nm 帯で分散がほぼゼロ**になるよう設計されている。
単一波長の長距離伝送には最適だった。**DWDM には最悪の条件になる。**

### 計算

位相不整合（等間隔チャネル、分散スロープ無視）:

```
Δβ ≈ (2π λ² / c) · Δf² · D
```

FWM 効率（標準形）:

```
η = α²/(α² + Δβ²) · { 1 + 4e^(−αL)·sin²(ΔβL/2) / (1 − e^(−αL))² }
```

| 記号 | 意味 |
|---|---|
| D | 分散 [s/m/m]（ps/nm/km × 10⁻⁶） |
| Δf | チャネル間隔 [Hz] |
| α | 損失係数 [1/m]（0.2 dB/km → 4.605×10⁻⁵） |
| L | スパン長 [m] |

### 結果（スパン80km / 0.2dB/km / 1550nm）

**チャネル間隔 50 GHz**

| ファイバ | D [ps/nm/km] | η | 相対 |
|---|---|---|---|
| **DSF（G.653）** | 0.0 | 1.000 | **100%** |
| DSF 実力値 | 0.5 | 0.361 | 36.1% |
| NZ-DSF（G.655） | 4.0 | 0.0091 | 0.9% |
| SMF（G.652） | 17.0 | 0.00049 | 0.05% |

**D=0 と D=17 で FWM 効率は 2,054倍（33.1 dB）の差。**

### 実務上の含意 — **推測は外れた。実際の対処はこう（2026-08-30 本人回答）**

計算上は「チャネル間隔を広げれば効く」（Δβ ∝ Δf² なので間隔を倍にすれば位相不整合は4倍）。

| チャネル間隔（D=0.5） | η |
|---|---|
| 50 GHz | 36.1% |
| 100 GHz | 3.4% |

**しかし現場ではこの手は使われていない。**

> **本人の回答（原文）**
> 実際に構築をするにあたって、コア区間で DSF しかない区間を使わざるをえない場合には、
> **長距離での DWDM 利用を避ける**ようにしています。
> 具体的には**利用区間を短く閉塞し、B2B 構成にしてリジェネを行います**。
> コスト的にはかなり効率が悪いですが、日本の場合は避けられません。特に地方や古い設備。
> **基本的に 50GHz もしくは flexible grid での運用**なので。

#### なぜ間隔を広げないのか

**グリッドが 50GHz または flexible grid で固定されているから。** 間隔を広げることは、
そのファイバに載せられる波長数を減らすこと（＝容量を捨てること）を意味する。
借りた区間で容量を捨てるより、**区間を切ってリジェネするほうが選ばれる。**

#### 実際の対処: 区間を短く閉塞して B2B リジェネ

- 長距離を1本で通さず、**短い区間に区切る**
- 区切った点で**トランスポンダを背中合わせ（B2B）に置き、電気段で再生（リジェネ）する**
- リジェネすると**そこで OSNR も非線形の蓄積もリセットされる**
- 代償は**コスト**。リジェネ点ごとにトランスポンダが2台要る

#### この記事・本との接続

**§4 で示した「多段では最悪区間が全体を支配する」の裏返し。**
支配してしまう悪い区間があるなら、**そこで切ってしまえばいい**。
OSNR の逆数和は、リジェネ点でリセットされる。

> **これは本の第7章（障害切り分け）と第4章（非線形）を繋ぐ実務的な結論。**
> 「計算上の最適解」と「運用上の選択」が違う理由が説明できる、非常に良い題材。

#### 学び（方法論として）

**物理から導いた含意が、運用の制約で否定されることがある。**
計算は「何が起きるか」を教えるが、「何をするか」は教えない。
→ 導出は出典なしで書けるが、**実務の結論は本人にしか書けない。** この分業を守ること。

import math

def eta(D_ps, df_GHz):

### 歴史的背景（2026-08-30 調査）

| 時期 | 出来事 |
|---|---|
| 1988年〜 | **1.55μm 帯を使った F-1.6Gb/s 方式が実用化。**再生中継間隔 80km で、ギガビット超の基幹伝送が初めて実現。この時期から **DSF が国内幹線系に導入**される |
| 1990年代 | インターネット普及で通信需要が急増。**既に敷設されたファイバに WDM を載せる**必要が生じる |
| — | **DSF に WDM を載せると、零分散波長付近で FWM が強く生じ、隣接波長間で混信**（→ 上の計算のとおり） |
| — | 対策として **NZ-DSF（G.655）**が設計される。1.55μm 帯で **2〜6 ps/nm/km** の少量の分散を持たせ、分散スロープも低く抑えた |
| 現在 | **既に地中にある DSF は残り続ける。** 特に地方・古い設備 |

**DSF が選ばれた理由**: 1.55μm は**伝送損失が最小**になる帯域。しかし G.652 はそこで約17 ps/nm/km の分散を持ち、高速化・長距離化の制約になる。**DSF は零分散波長を 1.55μm に移すことで、最小損失とゼロ分散を同時に取りにいった。** 当時としては合理的な最適化だった。
