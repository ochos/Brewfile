## 目次

### 第1章 なぜ1本のファイバに複数の波長を載せるのか

**動機から入る。** 技術の説明から始めない。

- ファイバを敷くには**莫大な費用と時間がかかる**。だから1本を使い倒したい
- 1本のファイバに1つの信号しか流せないなら、容量を増やすには本数を増やすしかない
- **色（波長）を変えれば、同じファイバに複数の信号を同時に流せる**
- これが波長多重（WDM）。密に詰めたものが DWDM

> 第1章は**無料公開章**にする（試し読み）。動機が伝われば続きを読みたくなる。

**執筆**: 公開情報のみ。**本人の手は不要。**

### 第2章 何を多重しているのか — 波長・周波数・グリッド

- 光の「色」は波長で表せるが、**多重の設計では周波数で考える**
- なぜか: **等間隔に並べたいのは周波数のほうだから**
- 換算: Δν = c·Δλ/λ² を導出する（`derivations.md` §2）
  - λ=1550nm で **0.1nm ≈ 12.5 GHz**
  - **50GHz グリッド ≈ 0.4nm 間隔**
- C 帯とは何か。なぜそこを使うのか（**損失が最小になる帯域だから**）
- flexible grid とは何か（固定グリッドとの違いだけ。深入りしない）

**執筆**: 全て導出可能。**本人の手は不要。**

### 第3章 dB と dBm — 光の世界の単位

**最初に必ずつまずくところ。** ここだけで独立した価値がある。

- なぜ対数を使うのか（**掛け算を足し算にするため**。損失も利得も掛け算だから）
- **dB は比**（無次元）／ **dBm は 1mW を基準にした絶対値**
- 演算のルール
  - dBm − dBm = dB（差は比）
  - dBm + dB = dBm（絶対値に利得/損失を足す）
  - **dBm + dBm は意味を持たない** ← 定番のつまずき
- 覚えておくと速い近似: 3dB ≈ 2倍 / 10dB ≈ 10倍 / −3dB ≈ 半分
- 実際に使う場面: スパン損失、光パワーバジェット

### 第4章 何が伝送を制限するのか — 4つの敵

**概観だけ。深入りしない。** ここが本②への入口になる。

| 制限要因 | 一言で | 本②での扱い |
|---|---|---|
| **損失** | 光は進むと弱くなる | 第2章 |
| **雑音** | 増幅すると雑音も増える | **第3章（OSNR）** |
| **分散** | 波長ごとに速度が違い、波形が崩れる | 第4章 |
| **非線形** | 光が強すぎると波長どうしが干渉する | 第4章 |

### 第5章 装置は何をしているのか

**役割で説明する。** 製品名や型番は出さない。

- **トランスポンダ** — 電気の信号を、指定の波長の光に変える／戻す
- **光増幅器** — 弱くなった光を増やす。ただし雑音も足す（第4章と接続）
- **合波器・分波器** — 複数の波長を1本にまとめる／取り出す
- **ROADM** — どの波長をどの方路へ流すかを、遠隔から変えられる装置
- **リジェネレータ** — 光を一度電気に戻して作り直す。**劣化がリセットされる**
- 全体の並び: どの順に何が入るのか（1枚の図）

**執筆**: 役割ベースなら公開情報のみ。**本人の手は不要。**
