## 第3章 dB と dBm — 光の世界の単位

### まず、たとえ話で

身長の話で考えます。

「170cm です」と「去年より 10% 伸びました」。この2つは、まったく種類の違う言い方です。前者は**絶対的な大きさ**、後者は**比**です。

比のほうは、それだけでは何も決まりません。「10% 伸びた」と言われても、元が何cm かを知らなければ、いま何cm かはわかりません。**比は、絶対的な大きさと組み合わせて初めて意味を持ちます。**

そして、この2つは混ぜてはいけません。「170cm から 10% 伸びた」は意味が通ります。しかし「**170cm と 165cm を足す**」は、何も意味しません。2人並べても 335cm の人にはならない。

光の世界では、**絶対的な大きさが dBm、比が dB** です。**dBm どうしを足してはいけない**のは、身長を足してはいけないのと同じ理由です。

では、なぜこんな単位をわざわざ使うのか。**光は進むほど、掛け算で弱っていく**からです。半分になり、その半分になり、さらに半分になる。掛け算のまま追いかけるのは面倒です。そこで、**対数にして足し算に変える**。それが dB の正体です。

:::message
ここまでで、この章の結論はほぼ言い終わっています。以降は、それを実際に使えるようにする話です。
:::

### なぜ対数を使うのか

光ファイバを進む光は、距離に応じて**一定の割合で**弱くなります。一定の量ずつ減るのではありません。**一定の割合**です。

たとえば、ある区間を通るたびに光が半分になるとします。3区間通れば、

$$
\frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}
$$

増幅器で持ち上げるのも同じで、**掛け算**です。つまり、光の設計とは**掛け算と割り算の長い連鎖**を追いかける作業になります。これは暗算できません。

ここで対数を使います。対数の性質は1つだけ覚えれば足ります。

$$
\log(A \times B) = \log A + \log B
$$

**掛け算が足し算になる。** これだけです。この変換をしておけば、区間の損失も、増幅器の利得も、部品の損失も、**すべて足し引きだけで見通せる**ようになります。

もう一つ利点があります。光の強さは、扱う範囲が非常に広い。送信端の光と、長距離を渡ったあとの光では、桁が大きく違います。対数にすれば、この広い範囲が扱いやすい数字の並びに収まります。

### dB は比。dBm は絶対値

定義はこれだけです。

**dB（デシベル）** — 2つのパワーの**比**を対数にしたもの。単位を持ちません。

$$
\mathrm{dB} = 10 \log_{10}\left(\frac{P_2}{P_1}\right)
$$

**dBm** — **1mW を基準**にしたパワーの絶対値。

$$
\mathrm{dBm} = 10 \log_{10}\left(\frac{P}{1\,\mathrm{mW}}\right)
$$

この定義から、いくつかがすぐ出ます。

| 値 | 意味 |
| --- | --- |
| 0 dBm | ちょうど 1mW |
| 0 dB | 変化なし（1倍） |
| 正の dB | 増えた（利得） |
| 負の dB | 減った（損失） |

**dBm の m は「1mW を基準にしている」という印**です。基準が付いているから絶対値になる。dB には基準がないので、比のままです。

### 演算のルール

ここが実務の中心です。3つ覚えます。

| 式 | 結果 | 意味 |
| --- | --- | --- |
| dBm − dBm | **dB** | 2点の差は「比」。区間の損失が出る |
| dBm + dB | **dBm** | 絶対値に、利得や損失を足す |
| **dBm + dBm** | **意味なし** | 身長どうしを足すのと同じ |

**dBm + dBm はなぜ無意味なのか。** 対数の世界で足すことは、元の世界で掛けることです。パワーとパワーを掛けた量には、光伝送で意味がありません。だから足してはいけない、というより、**足しても指す対象が存在しない**のです。

:::message alert
ただし「2つの光を合わせたときの合計パワー」を知りたい場合はあります。そのときは **dBm のまま足さず、いったん mW に戻して足し、また dBm に直します**。
たとえば同じ強さの光を2つ合わせれば合計は2倍です。2倍は次節のとおり約 +3dB なので、**「+3dBm」ではなく「元の値 +3dB」**になります。
:::

### 覚えておくと速い近似

暗算のための道具です。

| 値 | 倍率 |
| --- | --- |
| **3 dB** | **約 2倍** |
| **−3 dB** | **約 半分** |
| **10 dB** | **10倍** |
| −10 dB | 1/10 |

$10\log_{10}2 = 3.01$ なので、3dB は 2倍のごく良い近似です。この2つを組み合わせれば、たいていの値が概算できます。

- 6 dB = 3 + 3 → 2 × 2 = **4倍**
- 13 dB = 10 + 3 → 10 × 2 = **20倍**
- 20 dB = 10 + 10 → 10 × 10 = **100倍**
- −6 dB → **1/4**

「3 と 10 の組み合わせで作る」と覚えると、その場で計算できます。

### 実際に使う場面

**その1: 区間の損失を出す**

区間の入口と出口で光の強さを測り、**dBm どうしを引きます**。差が **dB**、すなわちその区間で失われた割合です。

$$
(\text{入口の dBm}) - (\text{出口の dBm}) = (\text{区間の損失 dB})
$$

これが、光伝送でもっとも頻繁に行う計算です。

**その2: パワーバジェット**

送信端の光の強さから始めて、**通っていくものを順に足し引きしていく**表を作ります。

<!-- 図: 送信 dBm から始まり、部品損失・区間損失を引き、増幅器の利得を足していく折れ線。縦軸 dBm、横軸 距離 -->

| 項目 | 種類 | 演算 |
| --- | --- | --- |
| 送信端の光の強さ | dBm | 出発点 |
| 合波器の損失 | dB | 引く |
| 区間の損失 | dB | 引く |
| 増幅器の利得 | dB | 足す |
| 分波器の損失 | dB | 引く |
| **受信端の光の強さ** | **dBm** | **結果** |

**dBm で始まり、途中はすべて dB の足し引き、結果はまた dBm。** これが対数を使う最大の理由です。もし倍率のままなら、この表は掛け算と割り算の列になり、見通しが一気に悪くなります。

### この章のまとめ

- 光は掛け算で弱る。**対数にすると掛け算が足し算になる**
- **dB は比**（単位なし）。**dBm は 1mW を基準にした絶対値**
- dBm − dBm = dB / dBm + dB = dBm / **dBm + dBm は意味を持たない**
- 3dB ≈ 2倍、10dB = 10倍。組み合わせれば暗算できる
- 区間損失もパワーバジェットも、**足し引きだけで書ける**

次章では、この足し引きの表に**何を書き込むことになるのか**を見ます。光の伝送を制限するものは、大きく4つあります。
