## 第6章 呼び方が食い違うもの — 現場の翻訳

### まず、たとえ話で

「大盛り」を頼んだとします。店によって、麺が増えるのか、具が増えるのか、器ごと大きくなるのかが違う。**頼んだ側と出す側で、同じ言葉から別のものを想像していた**——注文の時点では、誰も気づきません。会話は成立してしまうからです。気づくのは、出てきたときです。

光の部品にも、同じことが起きます。「400G」という同じ名前の中に、**中身の違うものが複数あります**。片方は太いケーブルを使い、片方は細いケーブルを使う。速さは同じなのに、**必要なものが違う**。

そして、これは「知らない人が間違える」話ではありません。**両方の担当者が、それぞれの現場では正しい**。ただ、想像しているものが違うだけです。だから会話は最後まで噛み合わないまま進みます。

この章は、その取り違えを防ぐための章です。**技術の章ではなく、確認の章**だと思ってください。

---

### 型番は何を語り、何を語らないのか

`400GBASE-DR4` のような名前は、いくつかの部分でできています。

| 部分 | 意味 |
| --- | --- |
| `400G` | 速さ |
| `DR` / `FR` / `LR` など | **どこまで届くか**（到達距離の区分） |
| 末尾の数字 | **何かが4つある**、ということ |

問題は最後です。**「4つ」が何を数えているのか、名前は教えてくれません。**

### 同じ「4」なのに、数えているものが違う

代表的な2つを並べます。

| | **400GBASE-DR4** | **400GBASE-FR4** |
| --- | --- | --- |
| 届く距離 | 500 m 程度 | 2 km 程度 |
| **末尾の4が指すもの** | **ファイバの本数** | **波長の数** |
| 使うファイバ | **8芯**（送信4 + 受信4） | **2芯** |
| 多重の仕方 | **並列**。4本とも同じ波長 | **1対に4波を多重** |
| コネクタ | **MPO**（多芯を1つにまとめたもの） | **LC**（2芯用の一般的なもの） |
| 分割 | **100G × 4 に分けられる** | **できない**（400G のまま） |

第1章から第2章にかけて、「1本のファイバに複数の波長を載せる」という話をしてきました。**FR4 はまさにそれです。** 4つの波長を、1対のファイバに載せている。

**ところが DR4 は違います。** 波長は1つのまま、**ファイバを4本並べている**。第1章のたとえで言えば、**FR4 は1本のトンネルに車線を引き、DR4 はトンネルを4本掘っている**。

<!-- 図: 上段 FR4=1対のファイバに4色／下段 DR4=4本のファイバに同色 -->

:::message alert
**「400G」と聞いても、次のどれも決まりません。**
サービスとして 400G が1本なのか 100G が4本なのか。必要なファイバが8芯なのか2芯なのか。コネクタが MPO なのか LC なのか。**名前が答えるのは速さだけです。**
:::

### 距離の記号も、一律ではない

`LR` を「10km」と覚えるのは危険です。同じ `LR` でも、**規格によって 6km のものと 10km のものがあります**。数字の付き方も揃っていません。

覚えるべきは値ではなく、**「距離の区分は名前だけでは確定しない」**という一点です。

### 標準化が追いつく前に、名前が増える

もう1つ厄介なことが起きます。**新しいものが出たとき、標準化が終わる前に各社が独自の名前を付けます。**

実例があります。「DR4 と同じ構成のまま、もう少し遠くまで届くようにしたもの」に、次のような名前が並びました。

| 呼び方 | 出どころ |
| --- | --- |
| `DR4+` | ベンダーの通称 |
| `XDR4` | あるメーカーの製品名 |
| `4x100G-FR` | 機能を並べた呼び方 |
| **`400GBASE-DR4-2`** | **後から標準化されて付いた正式名** |

**全部、同じものを指しています。**

そして標準名が付いたあとも、**現場では古い呼び方が残ります**。カタログには新しい名前、会話では古い名前。**どちらも間違いではない**ので、訂正されないまま併存します。

---

### 現場で実際に起きること

ここからは、実際に起きやすい2つの型を挙げます。**どちらも、誰かが無知だったから起きたのではありません。**

#### 型1 — SM か MPO か、話がすれ違う

**もっとも多い型です。**

「400G で」と話が進む。しかし片方は **LC を挿す前提**、もう片方は **MPO を挿す前提**でいる。速さの話はずっと噛み合っているので、**何かがおかしいと気づくまでに時間がかかります**。

気づく場所は、モノが届いたときとは限りません。**多くは、その前の打ち合わせの段階です。** 先方の技術担当や営業と話していて、途中で「あれ、想定しているものが違う」となる。

:::message
**発覚が早いのは良いことです。** 問題は、**そこまでの会話が噛み合っていなかった**という事実のほうです。前提が違ったまま進んだ分だけ、検討をやり直すことになります。
:::

#### 型2 — 前の世代の常識を、そのまま持ち込む

こちらは食い違いではなく、**思い込み**です。そして**費用に直結します**。

10G や 100G の時代、`LR` は標準的な選択肢でした。「とりあえず LR を選んでおけば届く」という感覚が、広く定着しています。

その感覚のまま、400G でも `LR` を選ぶ。**しかも、データセンターの中の接続で、です。**

よく聞いてみると、**`FR` で十分足りている**ことがほとんどです。数百メートルの接続に、10km 届く部品を買っている。**動きます。困りません。ただ、高い。**

:::message alert
**これは「間違い」として発覚しません。** 動いてしまうからです。誰も困らないまま、費用だけが乗ります。だから**指摘されないと、そのまま次の案件でも繰り返されます**。
:::

400G の世代では、距離の区分が細かく分かれました。**近い距離のための選択肢が増えている**のに、前の世代の感覚のままだと、その恩恵を受け取り損ねます。

### 名前ではなく、何で合意するか

以上を踏まえた確認項目です。**発注の前、できれば最初の打ち合わせの時点で**揃えます。

- [ ] **両端の型番が、完全に一致しているか** ← **最優先。これ以外は補助**
- [ ] サービスとして **400G が1本か、100G が4本か**
- [ ] ファイバは **MPO か、LC 2芯か**。芯数はいくつか
- [ ] ケーブルの構成（MPO どうし / MPO から分岐 / 2芯どうし）
- [ ] **その距離、本当に必要か**（型2の確認）
- [ ] その呼び方は**正式な規格名か、通称か**。通称なら**正式名も併記する**

:::message
**「400G 同士だから大丈夫」は、判定になりません。** 速さが同じでも中身が違うことがある、というのがこの章の全部です。
:::

### この章のまとめ

- 型番が語るのは**速さ**。ファイバの種類も、コネクタも、分割できるかも語らない
- **末尾の数字が何を数えているかは、型番によって違う**
- 標準化の前に各社が名前を付けるので、**同じものに複数の名前がある**
- 起きやすいのは2つ。**想定が違うまま話が進む型**と、**前の世代の感覚で過剰なものを選ぶ型**
- 合わせるべきは名前ではなく、**両端の型番の一致**
