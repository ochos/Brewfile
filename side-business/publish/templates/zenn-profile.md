## この文面が満たしていること

**変更するときは、この5つを崩さないでください。**

| 要素 | 該当箇所 | なぜ必要か |
|---|---|---|
| **専門と年数** | 「光伝送（DWDM）の設計を10年」 | 一目で何の人か分かる。年数が信用を作る |
| **社名を書かず経験を示す** | 「外資系通信キャリアで」 | 社名は書かない。だが経験の厚みは伝わる |
| **機材名** | 「Ciena 6500 / RLS」 | **指名検索の入口**。この語で探す人がいる |
| **他と違う視点** | 「借りたダークファイバの上に」 | **ここが差別化。**英語の資料にはこの前提がない |
| **読者の名指し** | 「配属1〜3年目のときに欲しかった」「営業の方にも」 | 読者が自分事として読む |

## 書いてはいけないこと

| | 理由 |
|---|---|
| **現職・前職の社名** | 発言が会社の見解と読まれる。守秘義務事故のリスクが跳ね上がる |
| **現職の事業内容の詳細**（買収・引き継ぎ等） | 進行中の情報。**最も危険** |
| 顧客名・回線名・案件名 | 論外 |
| 「副業で」「稼ぐため」 | 読者の信用を落とす。**動機は読者のためだと書く** |
| 「AI で書いています」 | 書く必要はない。**ただし Zenn の AI コンテンツガイドラインは確認すること** |
| 資格・学歴の羅列 | この領域では実務年数のほうが効く |

## 注意: 実名と「社名を書かない」の限界

**「外資系通信キャリアで DWDM 設計10年」＋実名**は、業界の人には**ほぼ特定できます**。
日本でこの条件に当てはまる人は多くありません。

社名を書かない意味は「特定されないこと」ではなく、**発言が会社の公式見解と受け取られないこと**にあります。
特定される前提で、**書く内容そのものを公開情報の範囲に保つ**ことが本質的な防御です。
