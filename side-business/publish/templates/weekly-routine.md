# 週次運用ルーティン（毎週日曜 21:00 / 30分）

設計理由: [`../../research/06-launch-ops.md` §5](../../research/06-launch-ops.md)

**本人の作業は「公開前レビュー」と「この週次ルーティン」の2つだけ。**
30分を超えたら3番を削る。3番が唯一の可変枠。

---

## タイマーを30分にセットして、上から実行する

### 1. 収益確認 — 5分

- [ ] Zennのダッシュボードを開く
- [ ] **今週の販売数**と**売上金額**を見る
- [ ] [`記録簿.xlsx`](../../記録簿.xlsx) の「記録」シートに1行足す
      （日付 / 項目=`Zenn Books 売上` / 金額 / 備考）

> 手取りは額面ではない。決済手数料3.6% + プラットフォーム手数料10%が引かれる（500円なら約434円）`[要確認]` → [Zenn よくある質問（販売）](https://zenn.dev/faq/sales)

### 2. 指標3つの記録 — 5分

- [ ] [`../../logs/TEMPLATE.md`](../../logs/TEMPLATE.md) をコピーして `logs/2026-WW.md` を作る
- [ ] 次の3つだけ転記する

```text
① 累計PV（Zennアナリティクス）:
② 本のページ閲覧数:
③ 今週の販売数:
```

> **この3つ以外の数字を見ない。** フォロワー数・いいね数・インプレッションは打つ手につながらないので見ない。

### 3. アウトリーチ — 15分（可変枠）

- [ ] 保存済みの検索5本を上から流し見る（5分）
      → 検索クエリは [`x-outreach.md`](x-outreach.md) 参照
- [ ] **回答できるものだけ**を最大2件選ぶ（2分）
- [ ] [`x-outreach.md`](x-outreach.md) のテンプレで返信する（8分）

> **0件の週は飛ばす。** この領域はXでの会話量が少ないので、0件が正常。無理に探すと無差別リプライになる。

### 4. 来週の予約投稿 — 3分

- [ ] 来週に公開予定があるか確認する
- [ ] あれば [`x-announce.md`](x-announce.md) から該当テンプレをコピーして予約投稿にセット
- [ ] なければ飛ばす

### 5. 判定 — 2分

**下の表を上から見て、該当する行があれば「次にやること」を1行メモするだけ。** ここで作業はしない。

| 条件 | 次にやること |
|---|---|
| 今週の販売が1冊以上 | **何もしない。** 記録するだけ |
| 4週連続で販売0 かつ 本のページ閲覧が月100未満 | **流入不足。** 記事をもう1本書く（本は触らない） |
| 4週連続で販売0 かつ 本のページ閲覧が月100以上 | **本のページで落ちている。** 説明文・目次・無料公開範囲を見直す（本文は触らない） |
| 記事のPVが公開4週で100未満 | **タイトルだけ**を [`keywords-dwdm.md`](keywords-dwdm.md) の入口①〜③の形に直す（15分） |
| Qiita版を出していない記事が公開7日以上経過 | [`crosspost-qiita.md`](crosspost-qiita.md) Step 1 で出すか決める |
| 4週以上 公開物がない | 公開の粒度が大きすぎる。次は**半分の長さ**で出す |
| 固定ポストが2週間以上同じ | 最新記事の告知投稿に差し替える |

## 月1回だけ追加（毎月第1日曜 / +15分）

- [ ] 狙ったクエリ3つを**シークレットウィンドウで検索**し、自分の記事の順位をメモ（10分）
      ※ Zennは自分のドメインではないため Google Search Console は使えない
- [ ] Zennの振込可能残高を確認（**振込手数料350円**がかかるため、少額での振込申請はしない）（5分）

---

## やらないこと（週次ルーティンに入れない）

- ❌ 毎日のX投稿（週次で予約投稿するだけ）
- ❌ はてなブックマークの確認
- ❌ アナリティクスの深掘り（指標3つ以外は見ない）
- ❌ 他人の記事の巡回
- ❌ 競合調査（この領域に競合がいないので意味がない）
- ❌ 本文の書き直し（判定表にあるのは「タイトル」「説明文」の修正だけ）
