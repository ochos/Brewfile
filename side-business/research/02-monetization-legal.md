2. **住所・電話番号を晒す前に設計を決める。**一度公開すると取り消せない。
3. **月1,000円なら税金の心配はほぼ不要。**ただし**住民税の申告義務は所得1円からある**点だけ覚えておく。

## A-3. 比較軸ごとの補足

### 入金サイクル
- **Stripe**：デフォルト週次（毎週金曜／入金日の4営業日前までの決済分）。ダッシュボードの「設定 → ビジネス設定 → 銀行口座とスケジュール設定」で週／月を変更可。**日本では日次入金は提供されていない。**
- **プラットフォーム系（BOOTH/note/Zenn/Codoc）**：ほぼ「振込申請 → 数営業日」。**振込手数料が 270〜350円**あるため、**月商1,000円の段階で毎月出金すると手数料負けする**。数ヶ月まとめて出金するのが合理的。
- **STORES**：月末締め翌月末（1万円未満は繰越）。**BASE**：申請から約10営業日、2万円未満は事務手数料500円。

### 個人でも審査が通るか
- **審査なし／実質なし**：BOOTH、note、Zenn、Codoc、楽天アフィリエイト、A8.net（登録時）
- **審査あり（個人でも通る）**：Stripe、PayPal、STORES、BASE、もしもアフィリエイト、バリューコマース
- **審査が重い**：Google AdSense、Amazonアソシエイト（180日以内3件の適格販売が前提）、Paddle
- Stripe の審査で落ちやすいポイント：**サイトに「特定商取引法に基づく表記」がない／商品説明が曖昧／返金ポリシーがない／サイトが未完成**。申請前にこれらを埋めておく。

### サブスク対応
- ◎ Stripe Billing、note メンバーシップ／定期購読、pixivFANBOX、Lemon Squeezy／Polar／Paddle
- ✕ BOOTH（買い切り）、Zenn、BASE / STORES ネットショップ（本体機能としては）

### 日本の消費税・インボイス対応
- **免税事業者（基準期間の課税売上高1,000万円以下）でいる限り、消費税の納税義務はない。**月商10万円＝年120万円なら余裕で免税事業者。
- **B2C（一般消費者向け）中心なら、インボイス登録はしなくてよい**のが基本線。買い手が消費者なら仕入税額控除を求めてこないため。
- プラットフォーム側が徴収する手数料（BOOTH の 5.6% 等）は、こちらが免税事業者なら仕入税額控除の話が発生しないので気にしなくてよい。

### 越境販売時の VAT / MoR
- **日本から国外の消費者向けにデジタルサービスを提供**する場合、日本の消費税は**不課税（国外取引）**となるのが原則。ただし役務提供地の判定が絡むので **要確認（所轄税務署／税理士）**。
- **相手国側の VAT**：EU は 2021/7 以降、B2C デジタルサービスに VAT 課税。自分で登録するなら OSS（One Stop Shop）制度。**現実的には MoR（Lemon Squeezy / Polar / Paddle / Gumroad）に丸投げするのが個人開発者の解**。
- 参考：2025/4/1 から日本で「**プラットフォーム課税**」が開始（国外事業者が特定プラットフォーム経由で日本の消費者にデジタルサービスを提供する場合、プラットフォーム側が納税）。これは**国外事業者が対象なので、日本在住のあなたには直接は関係しない**が、Apple/Google 経由で売る場合の建付けとして知っておくとよい。

### 必要な本人確認書類（共通）
- 顔写真付き本人確認書類（運転免許証／マイナンバーカード／パスポート）
- 本人名義の銀行口座（**PayPay銀行を1つ作っておくと BOOTH の振込手数料が無料になる**）
- 事業内容の説明、サイト URL（Stripe / STORES / BASE / ASP）
- 住所・電話番号（→ C-1 の特商法の論点と直結）

## A-4. 規模別の推奨構成

### 【月商1,000円フェーズ】推奨：BOOTH（DL販売）＋ note
**理由**
- 審査ゼロ・即日開始。特商法表記もプラットフォームの枠組みに乗れる。
- 固定費ゼロ。1,000円の売上に対し BOOTH なら手数料 101円（5.6%+45円）で済む。
- **Stripe を入れると、審査・特商法表記（住所/電話）・税務が一気に重くなる。この段階では割に合わない。**

**やらないこと**
- 独自ドメイン＋Stripe の自前決済（オーバーエンジニアリング）
- AdSense 申請（審査に時間を取られる割に月8,000円の支払基準に届かない）
- インボイス登録、開業届

### 【月商1万円フェーズ】推奨：BOOTH/note ＋ もしもアフィリエイト・A8.net
- ASP は **もしもアフィリエイト**を優先（**最低支払額1,000円・振込手数料無料・W報酬でボーナス12%**）。
- Amazon は**もしも経由**で提携すると、Amazon 本体の「180日以内に3件」審査を回避しやすい（要確認：Amazon 側規約の変更に注意）。
- 出金は数ヶ月まとめて（振込手数料対策）。

### 【月商10万円フェーズ】推奨：Stripe（国内）＋ MoR（越境）の二本立て
- 国内サブスク／自社サイト販売は **Stripe 直販**（3.6%）。月10万円なら手数料 3,600円 vs BOOTH 5,600円＋45円×件数。
- 海外顧客が出てきたら **Polar** か **Lemon Squeezy** を並走（5%+$0.50 は高いが、VAT 対応を自前でやるコストの方が圧倒的に高い）。
- ここで**開業届＋青色申告承認申請**、**特商法表記の住所問題**（バーチャルオフィス月1,000〜3,000円程度）を解決する。

## B-2. 審査に落ちやすい条件（AdSense／ASP共通）

**AdSense で落ちる典型パターン（2026年の傾向）**
- 記事数が少ない（目安：**10本以上、各2,000字前後**）
- **プライバシーポリシー・お問い合わせフォーム・運営者情報がない**（頻出の落ち理由）
- **AI で量産しただけの記事**は通りにくくなっている（E-E-A-T 重視）
- 無料ブログドメインは不利。独自ドメイン推奨
- 他社広告が貼られたまま申請している
- カテゴリがバラバラで専門性がない

**ASP の提携審査で却下される理由**
- サイトの記事数・情報量不足（10記事が実質的なライン）
- 商材と無関係なジャンル
- 誇大表現・薬機法／景表法に触れる表現
- 「準備中」ページが多い、更新が止まっている

**戦略上の示唆**：月商1,000円を最速で取るなら **AdSense より ASP のセルフバック（自己アフィリエイト）や物販アフィリ**の方が早い。AdSense は 8,000円の支払基準があるため、そもそも「月1,000円」の刻みでは現金が動かない。

## B-3. ステマ規制（景表法）— 必須のPR表記

**根拠**：景品表示法第5条第3号に基づく告示（**2023年10月1日施行**）。「一般消費者が事業者の表示であることを判別することが困難である表示」を不当表示に指定。

**チェックリスト**
- [ ] アフィリエイトリンクを含む記事の**冒頭（スクロールせずに見える位置）**に「**PR**」「**広告**」「**プロモーションを含みます**」等を明示
- [ ] SNS 投稿なら本文の先頭付近。ハッシュタグの羅列の末尾に埋もれさせない
- [ ] 「#ad」だけ、極小フォント、背景と同色、といった**不明瞭な表示はNG**
- [ ] 商品提供を受けた（サンプル・モニター）レビューも対象
- [ ] 自社商品の販売ページ自体は「事業者の表示であることが明らか」なので通常は表記不要

**重要な責任の所在**：措置命令・企業名公表の**名宛人は「広告主（事業者）」**であり、アフィリエイター本人ではない（2024/11 大正製薬、2025/3 医療法人社団スマイルスクエア等の措置命令事例）。ただし、**あなたが自分のデジタル商品を売る場合はあなた自身が「事業者」**なので、直接規制対象になる。また ASP・広告主から提携解除・報酬没収されるリスクは常にある。

# C. 法務

## C-1. 特定商取引法に基づく表記（最大の実務論点）

### 原則
通信販売を行う「販売業者」は、広告に **氏名（名称）・住所・電話番号** の表示義務がある（特商法11条）。個人でも「**営利の意思をもって反復継続して取引を行う**」なら販売業者に該当する。

### 回避策① 「請求があれば遅滞なく開示」による省略（特商法11条ただし書き）
消費者庁「通信販売広告 Q&A」で認められている運用。

**記載例**
> 住所・電話番号：特定商取引法第11条ただし書に基づき、記載を省略しております。ご請求があった場合には遅滞なく開示いたします。開示をご希望の方は下記フォームよりご連絡ください。

**成立条件（ここが重要）**
- 消費者から請求があったら、**購入の判断に間に合うタイミングで**（＝「遅滞なく」）開示できる体制があること
- 請求方法を画面上に明示していること（問い合わせフォーム等）
- 実際に請求が来たら本当に開示すること（拒否すれば表示義務違反）

**限界**：結局「請求されたら自宅住所を教える」ことになる。**匿名化の手段ではない。**

### 回避策② バーチャルオフィス
- 平成30年6月発行の特定商取引法**逐条解説で解釈が変更**され、消費者庁「通信販売広告Q&A（Q18）」で、「**現に活動している住所**」「**確実に連絡が取れる電話番号**」という要件を満たす限り、バーチャルオフィスの住所・電話番号の表示でよいとされている。
- 費用感：月1,000〜3,000円程度（住所のみ）＋電話転送オプション。
- **注意**：登記や実態のない「ただの私書箱」だと「現に活動している住所」と言えない可能性。契約時に「特商法表記に使用可」と明記しているサービスを選ぶ。
- **要確認**：消費者庁「特定商取引法ガイド」https://www.no-trouble.caa.go.jp/ の最新Q&Aで、自分のケースが該当するか。

### 回避策③ プラットフォームに乗る（月1,000円フェーズの最適解）
- **BOOTH**：ヘルプに「特定商取引法に基づく『販売業者』に該当しない場合は、連絡先や住所などを記載する義務はありません」との記載あり。個人の同人的・非反復的な販売なら不要という整理。ただし**継続的に売り続ければ「販売業者」に近づく**ので、規模拡大時は要再検討。
- **note**：有料記事販売について特商法表示の案内あり（noteヘルプセンター参照）。
- **⚠️ 誤解しやすい点**：「プラットフォームを使えば特商法が完全に免除される」わけではない。プラットフォームが**表記の枠組みと入力欄を提供**しているだけで、**義務の主体は出品者**。

### 電話番号について
- 携帯番号でも可。自宅固定電話である必要はない。
- **050番号（IP電話：SMARTalk 等）や電話代行サービス**の利用が実務的な選択肢。「確実に連絡が取れる番号」であることが要件。**要確認**：番号の種別自体に制限があるという明文はないが、通じない番号は違反。

### 2026年の動向
- 特定商取引法の改正検討会が **2026年1月に設置**され、**2026年夏頃に中間とりまとめ**を公表予定。改正法の公布・施行は 2027年以降の見込み。**個人事業者の住所開示ルールが見直される可能性があり、動向を追う価値がある。**

## C-2. 資金決済法・古物営業法が関わるケース

### 資金決済法
| ケース | 該当性 | 対応 |
|---|---|---|
| デジタルコンテンツを直接売る（BOOTH/Stripe） | **非該当** | 不要 |
| 自サービス内で「ポイント」「チケット」「クレジット」を**先払いで販売**し、後でサービスに使わせる | **自家型前払式支払手段に該当しうる** | 登録は不要（個人でも発行可）。ただし **毎年3月末・9月末の未使用残高が1,000万円超**なら財務局長への届出義務 |
| 他社のサービスでも使えるポイントを発行 | **第三者型前払式支払手段** | **登録が必要で、登録できるのは法人のみ → 個人は不可** |
| ユーザー間で送金・残高移転させる（投げ銭を現金化して他人に渡す等） | **資金移動業** | 個人には事実上不可。**設計段階で避ける** |

**個人開発での実務的な注意**：クレジット制／回数券／プリペイド型の課金設計にすると資金決済法の射程に入る。**月額サブスク（役務の先払いではなく期間契約）か都度課金**にしておけば通常は問題にならない。**要確認**：一般社団法人日本資金決済業協会 https://www.s-kessai.jp/ の Q&A、または財務局。

### 古物営業法
- **「古物」＝一度使用された物品／使用のために取引された物品**。**デジタルデータは「物品」ではないため対象外**（要確認：警察庁・所轄警察の解釈）。
- **物品の中古品を営利目的で反復継続して仕入れ・転売する**なら**古物商許可が必要**（都道府県公安委員会、手数料19,000円）。
- 自分の不用品を売るだけなら不要。
- 今回の想定（Webサービス／デジタル物販／アフィリエイト）では**通常は不要**。

## C-3. 景品表示法・ステマ規制（→ B-3 と併読）
- 施行：2023年10月1日

## C-5. 個人情報保護法・改正電気通信事業法（外部送信規律）

### 個人情報保護法
- 個人情報を取得する際は**利用目的をできる限り特定**し、**あらかじめ公表**するか取得後速やかに通知・公表する。→ プライバシーポリシーの Web 公開でこれを満たす。
- **問い合わせフォーム／コメント欄／GA4 を使っているなら、個人ブログでもプライバシーポリシーは必要。**

### 外部送信規律（電気通信事業法27条の12、2023年6月施行）
- 利用者の端末に、外部へ情報を送信させるプログラム（Cookie、タグ、GA4、広告タグ等）を送る場合、**送信される情報の内容・送信先・利用目的を、あらかじめ通知または公表**する義務。
- **適用対象の判断が難しい論点**：条文上の対象は「電気通信事業を営む者」のうち、**SNS・電子掲示板・オンライン検索サービス・ニュース配信等（第3号事業者）** 等。「**自社商品を紹介するだけの企業サイト／個人ブログは対象外**」という整理が一般的な一方、「ブログ運営者も対象になりうる」とする解説もあり、**解釈が分かれている**。
- **実務上の推奨**：判定に悩むより、**プライバシーポリシー内に「外部送信に関する公表事項」のセクションを作り、GA4／広告タグ／Stripe 等の送信先・送信情報・利用目的を一覧化**しておく。コストはほぼゼロでリスクが消える。
- **要確認**：総務省の解説ページ https://www.soumu.go.jp/main_sosiki/joho_tsusin/d_syohi/gaibusoushin_kiritsu.html

**掲示板・チャット・SNS的機能を持つWebサービスを作る場合は、明確に対象になる可能性が高い**ので、設計段階で公表ページを組み込むこと。

## C-6. 生成AIで作ったコード／画像の権利

### 日本法の建付け（文化庁）
- 参照：文化審議会著作権分科会法制度小委員会「**AIと著作権に関する考え方について**」（**2024年3月**）、および「**AIと著作権に関するチェックリスト＆ガイダンス**」（**2024年7月31日**）
- **学習段階**：非享受目的（著作権法30条の4）なら原則適法。ただし「享受目的が併存する場合」等の例外あり。
- **生成物の著作物性**：AI 生成物に著作権が認められるかは、**プロンプトの分量・内容、生成の試行回数、人間による創作的な加筆・修正の有無**等で判断。**ワンショット生成物は著作物と認められない可能性が高い＝他人にコピーされても差止められない**。
- **侵害の成否**：既存著作物との「**類似性**」＋「**依拠性**」で判断。**利用者が元ネタを知らなくても、AI が学習していれば依拠性が認められうる**点が重要。

### 各サービスの商用利用可否
| サービス | 出力の権利 | 商用利用 | 注意 |
|---|---|---|---|
| **Claude / Claude Code**（Anthropic） | 利用規約上「**顧客が出力を所有**」。Anthropic は出力に対する自らの権利をユーザーへ譲渡 | **可** | **Claude Code 本体のソースコードは OSS ではなく Anthropic 独自ライセンス（All rights reserved）**。改変・再配布は不可 |
| ChatGPT / Gemini 等 | 各社規約でユーザー帰属が原則 | 可（プランにより条件差） | 画像生成は別条件のことがある |
| 画像生成AI（各種） | サービスごとに大きく異なる | **要個別確認** | 無料プランは商用不可というケースが多い |

### 実務チェックリスト
- [ ] 使う AI サービスの**商用利用条項を実際に読んで、スクリーンショットを保存**しておく
- [ ] 生成コードに **OSS ライセンス下のコードが混入していないか**（特に有名ライブラリの実装をそのまま出してくるケース）
- [ ] **既存キャラクター・ロゴ・作風に酷似した画像**を商用利用しない
- [ ] 自社サービスに AI 生成物を使ったことの記録（プロンプト・生成日時）を残す
- [ ] AI 生成物単体は著作権保護が弱い前提で、**人間の編集を加える**
- [ ] **AI の学習に使われないプラン／設定**になっているか（機密コードを扱う場合）

# D. 税務・会社員の副業

> 以下は 2026年8月時点の一般情報です。**最終判断は所轄税務署または税理士に確認してください。**

## D-1. 「副業所得20万円以下は確定申告不要」の正確な条件

### 適用条件（すべて満たす必要がある）
1. **給与を1か所からのみ受けている**
2. その給与について**年末調整が済んでいる**
3. **給与所得・退職所得以外の所得の合計額が20万円以下**
4. 給与収入が2,000万円以下 等、その他の申告義務事由に該当しない

### よくある誤解
| 誤解 | 正しい理解 |
|---|---|
| 「売上20万円まで OK」 | ✕ **「所得」＝収入 − 必要経費**で判定。売上30万円・経費12万円なら所得18万円で不要 |
| 「20万円以下なら何もしなくていい」 | ✕ **住民税には20万円ルールが存在しない。所得が1円でもあれば市区町村への住民税申告が必要** |
| 「複数の副業も各20万円までOK」 | ✕ **合計**で判定 |
| 「医療費控除やふるさと納税で申告するときも副業分は書かなくていい」 | ✕ **確定申告をするなら、20万円以下の副業所得も含めて全部申告する必要がある**（20万円ルールは「申告しなくてよい」特例であって「除外してよい」ではない） |

### 月商別の目安（このプロジェクトの場合）
| 月商 | 年間売上 | 想定所得 | 所得税の確定申告 | 住民税申告 |
|---|---|---|---|---|
| 1,000円 | 1.2万円 | ほぼゼロ（サーバー代等の経費で赤字も） | 不要 | **必要**（自治体により少額なら不要な運用も／要確認） |
| 1万円 | 12万円 | 経費控除後で 20万円以下の見込み | 不要（要試算） | **必要** |
| 10万円 | 120万円 | 20万円を大きく超える | **必要** | 確定申告をすれば自動連携（別途不要） |

**住民税申告の実務**：所得が少額の場合、自治体によっては申告不要としている場合もある。**要確認：お住まいの市区町村の住民税担当課**。

## D-2. 開業届・青色申告をいつ出すべきか

### 提出期限
| 書類 | 期限 |
|---|---|
| **個人事業の開業・廃業等届出書**（開業届） | 開業日から **1か月以内** |
| **所得税の青色申告承認申請書** | 適用したい年の **3月15日まで**。ただし **1月16日以降に開業した場合は開業から2か月以内** |

### 判断基準
- **月商1,000円フェーズ：不要。**青色申告特別控除65万円の恩恵は、そもそも所得が小さいと意味がない。複式簿記の手間だけが増える。
- **月商1万円フェーズ：基本不要。**ただし「本気でやる」意思があるなら出しておくと、**開業初年度の赤字（PC・機材費）を青色申告で3年繰り越せる**というメリットはある。
- **月商10万円フェーズ（年120万円）：出すべき。**青色申告特別控除（e-Tax等で最大65万円／**2027年分から最大75万円**予定・要確認）の効果が大きい。

### 事業所得 vs 雑所得（重要）
- **青色申告ができるのは事業所得・不動産所得・山林所得のみ。**雑所得では青色申告不可。
- **令和4年10月の所得税基本通達改正（35-2）**により：
  - **帳簿書類の保存があれば、収入が300万円以下でも原則として事業所得に区分される**
  - 帳簿がない場合でも、収入が300万円超かつ事業と認められる事実があれば事業所得
  - ただし、**収入が僅少（例：概ね3年程度、本業の給与収入の10%未満）**、または**営利性が認められない（赤字が続き改善の努力もない）**場合は、個別に雑所得と判定されうる
- **示唆**：月商10万円（年120万円）は、会社員の年収に対して10%を超えるかどうか微妙なライン。**帳簿をきちんと付けることが事業所得認定の最大の武器**。

### 開業届のデメリット（会社員が知っておくべき）
- **失業手当（雇用保険の基本手当）が受けられなくなる**（開業＝自営開始とみなされる）。転職を考えているなら要注意。
- 健康保険の被扶養者だと、扶養から外れる可能性（会社員本人なら通常無関係）。
- 会社に知られるルートにはならない（開業届は税務署に出すもので、会社には通知されない）。ただし**就業規則の副業規定の確認は別途必要**。

## D-3. インボイス登録の要否判断

### 結論：**月商10万円（年120万円）規模なら、登録しないのが原則**

### フローチャート
```
売上先は誰か？
├─ 一般消費者（B2C）がほとんど
│    → 登録不要。免税事業者のままでよい。★このプロジェクトの想定
├─ 免税事業者・簡易課税の事業者
│    → 登録不要（相手が仕入税額控除を必要としない）
└─ 課税事業者（本則課税）の法人・個人が主要顧客
     → 相手から適格請求書を求められる可能性
       → 登録を検討（ただし値引き交渉で済むことも多い）
```

### 免税事業者でいられる条件
- **基準期間（前々年）の課税売上高が1,000万円以下**、かつ
- 特定期間（前年1〜6月）の課税売上高（または給与等支払額）が1,000万円以下

### 登録すると何が起きるか
- **強制的に課税事業者**になる（売上1,000万円以下でも）
- 消費税の申告・納付義務が発生（毎年3月31日期限）
- 帳簿・請求書の記載要件が厳格化（登録番号、税率区分、税率ごとの消費税額）
- **一度登録すると、原則2年間は免税事業者に戻れない**（要確認：登録取消は「翌課税期間の初日から起算して15日前まで」に届出）

### 負担軽減措置の状況（2026年時点・重要）
- **2割特例**（納税額を売上税額の2割に圧縮）：**個人事業主は2026年分の確定申告までが期限**
- **令和8年度税制改正**により、**フリーランス等の個人事業者に限り、税額を3割に変更したうえで2028年度まで2年間延長**される予定（「3割特例」）。適用条件は「個人事業主」「基準期間の課税売上高1,000万円以下」「確定申告書に3割特例適用の付記」となる見込み。**法人は対象外**。
- **要確認**：改正法の最終確定内容。国税庁インボイス制度特設サイト https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice.htm

### 越境販売と消費税
- 国外の消費者向けデジタルサービス提供は**日本の消費税は不課税**（国外取引）。免税事業者ならそもそも関係ない。
- MoR（Lemon Squeezy 等）を使う場合、**売主は MoR 側**なので、あなたは MoR に対する役務提供者という整理になる。**この場合の消費税の取扱いは要確認（税理士）**。

## D-4. 住民税を「自分で納付」にして勤務先に知られにくくする方法とその限界

### 方法
確定申告書 **第二表「住民税・事業税に関する事項」**の
**「給与、公的年金等に係る所得以外の所得に係る住民税の徴収方法」→「自分で納付」に○** を付ける。

これにより、副業分の住民税は勤務先の給与天引き（特別徴収）に合算されず、自宅に納付書が届く（普通徴収）。

### 限界（重要 — 「絶対バレない方法」ではない）
1. **副業が「給与所得」（アルバイト・パート）だと普通徴収を選べない。**給与所得の住民税は原則特別徴収と法定されており、本業の会社に合算通知が行く。
   → **本件（デジタル物販・アフィリエイト）は事業所得／雑所得なので、この方法は有効。**
2. **自治体によっては普通徴収を認めない／原則特別徴収としている**運用がある。事前に市区町村の住民税担当課へ確認するのが確実。
3. **チェック漏れ**：e-Tax の入力で選択し忘れると特別徴収になる。提出前に必ず確認。
4. **住民税以外のルート**では知られうる：社会保険（一定規模になると）、SNS での発信、同僚経由、確定申告そのものではない。
5. **そもそも就業規則違反かどうかは別問題。**厚生労働省は**モデル就業規則から副業の原則禁止規定を削除し、届出制を前提とした条文に改定**している。**2026年には労働時間通算の見直しを含む法改正の動きもある（要確認）**。まずは自社の就業規則を確認し、可能なら正規のルートで届け出るのが健全。

## D-5. 経費にできるもの

### 全額または高割合で経費計上しやすいもの
| 項目 | 勘定科目例 | 備考 |
|---|---|---|
| **レンタルサーバー・VPS・クラウド（Vercel, Cloudflare, AWS 等）** | 通信費／支払手数料 | 事業専用なら全額 |
| **ドメイン代** | 通信費 | 全額 |

| **SaaS 利用料（Figma、Notion、デザイン素材、フォント）** | 支払手数料 | |
| **決済手数料・振込手数料（Stripe / BOOTH / note）** | 支払手数料 | |
| **技術書・オンライン講座・カンファレンス参加費** | 新聞図書費／研修費 | |

| **バーチャルオフィス利用料** | 地代家賃／支払手数料 | 特商法対策の費用も経費 |

### 家事按分が必要なもの
| 項目 | 按分基準 | 目安 |
|---|---|---|
| **家賃** | 作業スペースの床面積比、または使用時間比 | 10〜30%程度が現実的 |
| **電気代** | 使用時間比 | 10〜30% |
| **インターネット回線・スマホ代** | 使用時間比 | 20〜50% |
| **PC・周辺機器** | 業務使用割合 | |

**按分のルール**：合理的な基準で計算し、**その根拠（計算式・使用時間の記録）を残す**こと。「なんとなく50%」は否認リスク。

### PC等の資産の扱い
| 取得価額 | 扱い |
|---|---|
| 10万円未満 | **消耗品費として全額即時経費** |
| 10万円以上20万円未満 | 一括償却資産（3年均等償却） or 少額特例 |
| 20万円以上 | 通常の減価償却（PCは4年）、または少額減価償却資産の特例 |

**【2026年の重要改正】少額減価償却資産の特例**
- **令和8年度税制改正**により、対象が「**30万円未満 → 40万円未満**」に引上げ
- 適用時期：**令和8年（2026年）4月1日以後取得分**
- 年間合計上限 300万円は据置き、適用期限は令和10年度末（2029年3月31日）まで3年延長
- **青色申告事業者であることが要件**（→ 白色や雑所得では使えない）
- **要確認**：改正法の最終条文。国税庁 https://www.nta.go.jp/

### 経費計上の前提条件
- [ ] **領収書・請求書・クレジットカード明細を保存**（原則7年）
- [ ] **電子帳簿保存法**：**電子取引（メール添付のPDF請求書、Web上のDL領収書）は電子データのまま保存が義務**（2024年1月〜、個人事業主も対象）。プリントアウト保存だけでは不可。**要確認**
- [ ] 事業用の**銀行口座・クレジットカードを本業と分ける**（記帳が劇的に楽になる。月1,000円フェーズでも先にやる価値あり）
