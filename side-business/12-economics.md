## 2. 開発ツール費 — ここが最大の固定費

| 項目 | 月額 |
|---|---|
| Claude Code Pro | 約3,100円（$20） |
| Claude Code Max 5x | 約15,500円（$100） |

**インフラ費よりツール費のほうが1桁大きい。** これを「事業の固定費」に含めるかどうかで損益分岐が全く変わる。

### 推奨する扱い

**M1 の間は、Claude Code 費用を事業原価に入れない。**

理由: この段階の Claude Code は「学習と生産性のための自己投資」であり、副業をやめても価値が残る。ここを原価に入れると、月1,000円の目標が最初から赤字確定になり、判断が歪む。

**M2 に到達した時点で原価に繰り入れる。** そこからは「ツール代を回収できているか」が正しい問いになる。

## 3. 販売手数料

### Zenn Books（M1 の主戦場）— 2026-08-30 確定

**2段階で引かれる。**

```
500円（販売価格）
 → 決済手数料 3.6%      −18円   = 482円
 → Zenn 利用料 10%      −48円   = 433円  ← 手取り
```

**実効手数料率 13.24% / 受取率 86.76%**（公式計算例: 1,000円 → 868円）

| 月商 | 冊数 | 手取り |
|---|---|---|
| 1,000円（M1） | 2冊 | **867円** |
| 10,000円 | 20冊 | 8,676円 |
| 100,000円 | 200冊 | 86,760円 |

> 出典は Zenn の公式FAQ だが、**本セッションからは 403 で直接読めていない**（第三者情報と実装ソースによる裏取り）。**販売開始前に必ず本人が公式ページで再確認すること。**

### 他チャネルとの比較

| チャネル | 手数料 | 500円商品の手取り |
|---|---|---|
| Chrome拡張（Stripe 直販） | 3.6% + 決済処理 | 約478円 |
| BOOTH（DL販売） | 5.6% + 45円 ※2025年10月改定 | 約427円 |
| **Zenn Books** | **実効 13.24%** | **433円** |
| note | 販売手数料 + 決済手数料 | 約380〜420円 |
| ランサーズ | 16.5% | 418円 |
| ココナラ | 22% | 390円 |

**Zenn は BOOTH とほぼ同水準。** 手数料で選ぶ理由はないが、**集客チャネル（記事）と同一プラットフォームである**という利点がそれを上回る。

### 出金のルール

| 項目 | 内容 |
|---|---|
| 振込手数料 | **1回 350円**（申請ベース） |
| 現金受取の下限 | 残高 **1,000円以上** |
| 放置した場合 | 確定から**5ヶ月**でAmazonギフト券に自動切替 |

> **毎月出金してはいけない。** 月商1,000円（手取り867円）で毎月申請すると、350円 = **手取りの4割**が消える。
> **5,000円以上貯めてから、年に1〜2回申請する。** ただし5ヶ月の自動切替期限があるので、放置しすぎない。

## 4. 損益分岐

### M1 段階（インフラ費0円）

固定費がゼロなので、**1冊売れた時点で黒字**。金銭的な下振れは構造的に存在しない（失うのは時間だけ）。

### M2 段階（Claude Code Pro を原価に含めた場合）

```
月額固定費 = 3,100円（Claude Code Pro）+ 150円（インフラ）= 3,250円

500円商品の手取り = 433円（確定値）
→ 損益分岐 = 3,250 ÷ 433 ≒ 月 7.5 件 → **8冊**

500円/月サブスクの手取り ≒ 478円
→ 損益分岐 = 3,250 ÷ 478 ≒ 継続課金 7 人
```

**M2（月1万円）はこの分岐点を明確に超える。** 月1万円 = 手取り8,676円 に対し固定費3,250円で、粗利 5,426円。

### M3 段階

```
月額固定費 = 3,100円（Claude Code Pro）+ 4,750円（インフラ）= 7,850円
月商100,000円 → 手数料控除後 約95,000円
粗利 = 約87,000円（粗利率 87%）
```

**年間の粗利が約104万円** となり、この時点で確定申告・開業届・青色申告が現実的な検討対象になる（→ [`13-risks.md`](13-risks.md) の税務セクション）。

## 6. 「月1,000円」の経済的な意味

正直に書くと、**月1,000円という金額そのものには経済的意味はない**。時給に直すと、90日で82時間かけて累計3,000円なので**時給37円**。

この段階の目的は金額ではなく、次の3つを確定させること:

1. **他人が金を払う商品を作れた** という事実（作れない人が大多数）
2. **どの経路から売れたか** という情報（これがないと次に何を増やすべきか分からない）
3. **決済・入金・税務の一連の流れを一度通した** という経験

**時給が意味を持ち始めるのは M2 以降**、それも「先月の顧客が今月も払う」ストック収入が積み上がってから。M1 はそこへの通行料と考える。
